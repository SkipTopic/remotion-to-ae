# 量化审核与验收

"看一遍觉得还行"是最不可靠的验收方式。用数字找出问题区间，再用抽帧确认。

## 第一步：逐帧量化扫描

```bash
python scripts/qa_scan.py <video.mp4>
```

脚本把画面降采样到 192×108 灰度，逐帧算亮度均值、标准差、与前帧的平均绝对差（MAE），输出：

```
luma mean  : avg=141.88 min=0.04 max=226.82
frame diff : avg=2.495 median=0.239 p10=0.001 p90=6.424 max=143.71

[纯白帧] 0 帧
[近黑帧 mean<12] 13 帧 -> [0,1,2,7883,...]
[连续>=10帧 近静止] 71 段, 合计 4188 帧
  frames 3107-3329  (103.57s-110.97s)  len=223 (7.43s)
[帧差>45 的硬跳变] 45 处 -> [96, 240, 496, ...]
[4秒窗口] idx  start-end  mean  std  diff_avg  maxdiff
  26  3120-3240   87.8  18.6   0.022  0.18  <<DEAD
```

## 指标判读

| 指标 | 健康值 | 超标含义 |
|---|---|---|
| 纯白帧（mean>236 且 std<3.2） | **0** | 转场收拢到 0 半径、遮罩漏底、或该帧内容缺失 |
| 近黑帧 | 仅首尾黑场 | 中途黑帧 = 段落没内容 |
| 连续 ≥10 帧近静止 | **段数 ≤3，合计 <1.5%** | 静态分镜、文字落定后无第二层运动 |
| 帧差 = 0 的帧 | **0** | 颗粒层按秒换 / 完全静态图层，像素级重复 |
| 帧差 >45 的硬切 | 每处都要能看到过渡 | 0 帧硬切、闪白、插错帧 |
| 帧差 P10 | >0.2 | 最静的 10% 帧是否还"活着" |
| 4 秒窗口 `diff_avg < 0.5` | 无 | 该窗口基本是一张静图 |

**帧差 = 0 是最强的死帧证据**：说明连噪点都没动。常见根因是
颗粒层用 `Math.floor(frame/30)%3` 每秒钟才换一次纹理，静态底图下就产生 30 帧完全相同的像素。

## 第二步：必须用高分辨率复核

192×108 的降采样会**平均掉细微推镜**，把"缓推 1.045 倍"算成"几乎不动"。
所以凡是"这段是死的"这种结论，必须用 960×540 复核一次：

```python
# 对可疑区间逐帧算 MAE（960×540）
d = np.abs(np.diff(frames, axis=0)).mean(axis=(1,2))
```

判读：

- 帧差在 `0.001–0.02` 量级 → **确实是死的**，肉眼绝对看不出运动
- 帧差在 `0.3–1.0` → 有极缓运动（推镜 / 光流动），可接受
- 帧差 >2 → 正常运动

一次真实复核结果：

```
[96.5-99.0s]  75 帧 @960x540 | diff avg=0.027  → 确认死帧
[244.0-247.0s] 90 帧 | diff avg=0.019, 大量帧恰好 0 → 完全冻结
[150.0-152.0s] 60 帧 | diff avg=3.632          → 对照组，正常
```

## 第三步：人工抽帧

量化只告诉你"哪里不动"，不告诉你"为什么难看"。抽帧看内容：

```bash
# 全片总览：每 8 秒一帧，6×7 拼图
ffmpeg -y -i in.mp4 -vf "fps=1/8,scale=240:-1,tile=6x7" -frames:v 1 -q:v 3 overview.jpg

# 可疑区间：每秒一帧
ffmpeg -y -ss 103.5 -t 8 -i in.mp4 -vf "fps=1,scale=320:-1,tile=4x2" -frames:v 1 -q:v 3 dead.jpg

# 转场：每 0.1 秒一帧
ffmpeg -y -ss 142.9 -t 0.8 -i in.mp4 -vf "fps=10,scale=320:-1,tile=4x2" -frames:v 1 -q:v 3 trans.jpg
```

抽帧必查清单：

- [ ] 画面内有没有**可辨文字**（招牌、书封、价签、水印）
- [ ] 有没有**人物/人脸**
- [ ] 有没有**高饱和大色块**破坏整体基调
- [ ] 文字是否**压在图片主体上**、一帧内能否读完整句
- [ ] 相邻两张并排图片的**倾斜方向**是否合理（并排应反向）
- [ ] 转场是**溶接/翻页**还是硬切
- [ ] 有没有**单帧闪白 / 闪黑**

## 第四步：音画对位

```bash
# 响度（注意不要加 -v error，否则 Summary 被吞）
ffmpeg -hide_banner -nostats -i in.mp4 -af "ebur128=peak=true" -f null - 2>&1 | grep -A12 Summary

# 静音断点
ffmpeg -hide_banner -nostats -i in.mp4 -af "silencedetect=noise=-45dB:d=0.8" -f null - 2>&1 | grep silence_
```

- 成片响度应接近原曲（差 0.2 LU 内说明是原样过带，没有二次压缩）
- 出现意料之外的静音段 = 混音漏了或 `-shortest` 截断

歌词与画面对位：拿 LRC / ASR 时间轴和画面文字出现帧逐句比。
±0.4 s 内可接受，超过就要整体平移。
